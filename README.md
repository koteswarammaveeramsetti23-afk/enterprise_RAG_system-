## project Over view
This project is an enterprise RAG system that allows user to ask questions about uploaded documents and receive context-based answers.
## Technologies Used
- python
- sentence Transformer
- FAISS
- FLAN-T5 Local LLM
- Gradio
- pypdf
## Features
- PDF document processing
- Document Chunking
- Text enbedding
- Semantic search
- Local LLM based answers
- User login and roles
- Error handling
- Interactive chatbot interfernce
## How it works
PDF → Text Extraction → Chunking → Embeddings → FAISS Search → Local LLM → Answer
